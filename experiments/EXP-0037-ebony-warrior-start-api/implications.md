# EXP-0037 implications

The installed Ebony Warrior quest is serialized as a CLOC quest, while both inspected GOG Papyrus start wrappers gate a nondefault event ID before ordinary deferred startup. This weakens the idea that simply invoking `Quest.Start` or `Quest.SetStage` from an ordinary script would bypass the level-80 CLOC selection. It does not prove the installed Steam executable behaves identically or that a separate Story Manager/native route cannot be composed.

No causal edge connects this event-scope guard to OBJ-2 armor protection, AV39 mitigation, HitData, or skill XP. Q-0030 will inspect remaining Dragonborn actor, placed-reference, scene, package, and VMAD-bearing records for a statically configured alternate encounter/start path. Any positive candidate still requires a clean level-one Steam runtime test with exact order, numeric player level, quest running/stage, alias-fill, and actor placement observed.
