# Expected discriminants

1. Whether the child XESP parent FormID resolves to the named enable-marker reference.
2. Whether XESP Flags has opposite-parent or Pop In bits.
3. Whether the child and parent REFR header set the schema-defined Initially Disabled bit under their respective base-type variants.
4. Whether any resulting base-field pattern establishes more than serialized parent inheritance. It cannot establish loaded reference state, collision geometry, route accessibility, stage-trigger execution, or a level-one transition.

EV-0282 resolves discriminants 1–3 for installed Dawnguard.esm base records. Discriminant 4 remains a separate runtime and geometry question.
