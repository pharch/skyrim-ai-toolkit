# Expected discriminants

| Model | Evidence that would support it | Evidence that would weaken it |
|---|---|---|
| H1: CLOC level gate | A pre-start `GetLevel` CTDA, PSC call, or build-identified native level read on the CLOC event path | Complete bounded CLOC source walk with no level predicate; natural level-one QUST start with numeric level preserved |
| H2: distinct state/world paths | CLOC and SCPT children select separate QUSTs; only the world QUST contains the level/location condition group | A shared pre-start native or script condition feeding both routes |
| H3: levelled actor selection | The exact CLOC alias-fill route resolves its `TPLT` to the linked LVLN under the target player level | A target-specific call path proves the LVLN is not consumed, or a natural actor-base capture shows no level-dependent selection |
| H4: TPLT chain unused by CLOC | The target-specific alias-fill route bypasses TPLT or the required template flag prevents the LVLN chain from being used | A target-specific path or natural observation shows one of the linked LVLN variants filled into the CLOC alias |

The direct Dragonborn records establish serialized links and entry thresholds,
not runtime alias fill. The GOG override establishes a general template-copy
code path, not Steam equivalence or the selection of these exact records.
The decisive runtime discriminator is a clean level-one Steam sequence with
numeric player level, `DLC2CultistAmbush` state/stage, alias fills, and actor
base FormIDs recorded through a read-only observer; EV-0260 currently lacks
those artifacts.
