# Implications

The complete source census rejects the narrow model that GetLevel predicates occur only in Story Manager and already-screened dialogue records. It discovers a DA03Start guard greeting with matching level-10 conditions on both its package and the linked INFO record. The gate is attached to this guard conversation path; the captured source does not show the INFO response calling `SetStage`, and the bounded UESP page describes the guard as directing the player to Lod.

The highest-value continuation is to enumerate every Skyrim.esm DIAL and INFO child owned by DA03Start, then identify Lod-specific topics and their conditions, localized response IDs, and any VMAD/TIF fragment bindings. Rival models: (H1) Lod's ordinary direct dialogue has an ungated callback that starts DA03/main DA03 at level 1, bypassing the gated guard introduction; (H2) Lod's relevant topics or quest-start callback carry the same level/stage gate or depend on a gated alias. Discriminant: the complete source-layer topic/INFO join plus the fragment-to-PEX mapping, followed by a clean level-one run if static source reveals an ungated candidate.

This is not yet a level-one bypass, access result, or user-profile winner. The exact runtime test still requires the complete active order for the identified Steam AE executable, a clean level-one save, a read-only observer, and before/after DA03Start/DA03 running state, stage and alias observations under ordinary dialogue. No causal edge to the OBJ-2 armor protection/XP mechanism is supported: the observed conditions act on quest/dialogue selection, and the extracted Papyrus path does not touch armor, hit data, ActorValues or armor-skill awards.
