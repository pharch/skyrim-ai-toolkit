# Protocol

## Target and version

- Current AE executable ProductVersion/hash: **unknown**; required command is `python3 scripts/python_env.py run tools/ae_preflight.py` on Windows.
- Complete active load order/profile: **unknown**; do not treat absence of a cast as a negative finding until it is verified.
- Historical candidate: WICast form-list, QUST, parent node, and effect record analysis; location and event selection remain unobserved.
- Lane now: `mechanism_inference`; no runtime event is scheduled.

## Baseline and rollback

After target verification, use a clean disposable save and record level, quest state, location/cell, current-location `WIComplexInteractionToggle` value, player AV39, active effects, and starting Block/armor skill budgets. Save a baseline copy and restore it before each event/control. No forced quest stage, forced cast, added effect, or record edit.

## Minimal controls and capture

1. Resolve the winning WICast/SMBN/FLST/QUST/MGEF records in the complete active profile.
2. Establish ordinary reachability of the candidate location. The historical Sovngarde predicate is a lead, not proof that the route is level-one reachable.
3. Observe a natural eligible event. Capture event/quest identity, source actor, spell form, target, location counter and predicate result, AV39 and ActiveEffect state before/after.
4. Control: observe a comparable non-candidate location or ordinary cast event; verify the logger sees events and no candidate spell/AV39 change occurs.
5. If a natural cast is observed, only then plan a separate blocked-hit measurement under EXP-0009's matched controls.

## Interpretation

A Marked-for-Death form in a list does not establish selection, target, or level-one reachability. A candidate result requires an unforced player-targeted event and measured AV39 change. Preserve raw trace, save/profile/build identity, and observer liveness; classify any forced event as `diagnostic_intervention` only.
