# Competing models

- **Q67-H1:** a hard above-level-one predicate gates every ordinary DA05 initiation path. Predicted evidence: a necessary `GetLevel` or equivalent predicate in QUST, Story Manager, linked INFO, script fragment, or parent dispatch.
- **Q67-H2:** a level predicate gates the usual dispatch, while a separate ordinary Sinding or Mathies dialogue callback can start DA05 before that gate.
- **Q67-H3:** the screened official DA05 source path contains no above-level-one player-level gate. Whether any ordinary level-one interaction is available and produces useful progress remains a separate runtime question.

The source screen can falsify a gate in its covered path. It cannot establish that every actor or topic is naturally available at level 1, or that the player can reach desired content in a live profile.
