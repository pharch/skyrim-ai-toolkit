2. Verify Skyrim.esm identity and retain fixed official-master source scope. Do not infer a profile winner.
3. Trace DA05 QUST flags/conditions, Story Manager parent/child records, DA05-owned DIAL topics, and INFO children using their source group ancestry.
4. Decode CTDA function indices only from recorded xEdit schema evidence. Preserve raw CTDA bytes and unknown indices.
5. Inspect linked VMAD fragment names and relevant PEX scripts from Skyrim - Misc.bsa. Treat classic PEX disassembly as bounded bytecode evidence, not a complete decompiler.
6. Keep quest running state, stage/journal transition, actor/topic availability, and functional progression distinct. Do not force level or quest state.
7. Record a separate natural level-one interaction and no-contact runtime control. Do not claim a vanilla reproduction from static records.
