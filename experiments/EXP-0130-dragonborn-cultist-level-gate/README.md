Frontier Q-0081 began by testing whether the level-25 `DLC2WE09` world encounter is separate from the documented `DLC2CultistAmbush` path after The Way of the Voice. The initial source lead is revision-pinned local UESP text [EV-0653]. The first official QUST export unexpectedly links `DLC2CultistAmbush` to `DLC2WE09Chance` and attaches `DLC2WE09ActorScript`, so the investigation now also tests whether the labels describe distinct entry points into shared event machinery [EV-0654].

This experiment is a source screen only. The five-master records establish distinct CLOC and SCPT QUST routes; the latter's GetLevel >=25 and Solstheim rows are both OR-flagged, and the identity-checked GOG evaluator groups consecutive OR rows [EV-0656]–[EV-0669]. The bounded expression is earlier chance/stage predicates AND (level >=25 OR current location is Solstheim), as a GOG static inference applied to official record bytes. It does not prove Steam condition evaluation, list timing, a level-one start, or a vanilla glitch. Any level-one quest/event transition requires a verified clean Steam profile/full order, numeric level-one save, ordinary trigger controls, and read-only observation under EV-0260. Console or script forcing cannot validate a vanilla route.
