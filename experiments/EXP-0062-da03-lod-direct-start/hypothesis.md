# Hypothesis

## H1 — ungated Lod start

At least one Lod-owned player dialogue topic is available without the level-10 guard condition and reaches an INFO TIF or alias script that starts DA03Start or DA03 below level 10.

## H2 — guarded or dependent Lod path

Lod's relevant dialogue is also level/stage gated, or it only advances a route whose start depends on the gated guard greeting or another gated event.

This experiment is hypothesis-testing, not a vanilla reproduction. A static SetStage call is only a candidate until exact Steam level-one state is measured.
