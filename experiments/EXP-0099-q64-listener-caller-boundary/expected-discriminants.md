# Expected discriminants

1. A concrete writer must target the exact hkpConstraintInstance +0x40/+0x48 array/count.
2. Its entry object must be tied to a concrete class and slot +0x8/+0x10 targets.
3. Follow that object and target to Actor::UseSkill or the mapped skill-progress sink with an AV11/AV12 argument.
4. A missing symbol reference, generic caller, or unrelated offset match is inconclusive.
