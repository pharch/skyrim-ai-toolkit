# EXP-0051 — Positive-rating Clothing ARMO candidate

This experiment screens official ARMO/ARMA records for clothing-class items with positive base armor rating, compares the item classification with the GOG hit receiver's Heavy/Light skill selector, and checks the PlayerCharacter armor-factor getter. Static source evidence can identify a candidate but cannot establish effective protection or a Steam zero-XP result.

See [hypothesis.md](hypothesis.md), [expected-discriminants.md](expected-discriminants.md), [protocol.md](protocol.md), and [results.md](results.md). Private source captures and hashes are in the ignored TX-20261016-0044 evidence directory and EV-0309 capture manifest.
