# Tool compatibility matrix

The canonical compatibility matrix is
[`TOOL_CAPABILITY_MATRIX.md`](TOOL_CAPABILITY_MATRIX.md), which records each
tool's prerequisites, available smoke tests, and external blockers. Candidate
paths and existence checks are summarized in
[`TOOL_PATH_VERIFICATION.md`](TOOL_PATH_VERIFICATION.md). Do not treat a path
from the legacy checkout as current compatibility evidence.
